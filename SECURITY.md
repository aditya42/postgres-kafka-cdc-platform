# Security

This repository is a local portfolio/reference environment. Default passwords and plaintext listeners exist only to make the demo self-contained.

Do **not** use the local defaults in production. Production deployments should use IAM/workload identity for S3, TLS/SASL for Kafka, PostgreSQL TLS and least-privilege roles, a secret manager, network policies/security groups, encrypted storage, connector ACLs, and private service endpoints.
